# Local database configuration

Before running the application on a new machine, copy each example file to the matching local file and enter the database connection settings:

- `con_lda.local.example.php` to `con_lda.local.php`
- `config_dashboard.local.example.php` to `config_dashboard.local.php`
- `admin/con_lda.local.example.php` to `admin/con_lda.local.php`

Local configuration files are excluded from Git. Existing local settings have been preserved on this machine.
- `admin/check_login.local.example.php` to `admin/check_login.local.php`
